# Hotel-Management-Networking---cisco
Designed and configured a three-floor Hotel Management Network in Cisco Packet Tracer with 3 routers and 3 switches, connecting 8 departments through separate VLANs.
Implemented Inter-VLAN Routing using 802.1Q
DHCP pools for dynamic IP addressing
OSPF Area 0 for dynamic routing
Serial DCE links between routers
Trunk and access port configurations
Wireless connectivity for laptops and mobile devices
SSH with RSA authentication for secure remote router administration.
